# SZL Spectral Proof v2

## Role

`a11oy.net` is the independent public record origin. Spectral Proof makes it feel technically advanced and connected to the A11oy product estate without making it resemble an operational console or implying that decoration is evidence.

## Visual language

The system uses a strictly neutral forensic prism:

- black, white, gray, and alpha only;
- ledger planes and ruled evidence fields;
- checksum and topology nodes;
- restrained scan lines;
- refracted monochrome light;
- route-specific archival geometry.

Text, machine-readable records, hashes, labels, and source links continue to carry evidentiary meaning. The visual field carries none.

## Interactive records

Interactive pages receive six local DOM/CSS layers:

1. perspective grid;
2. route-specific ledger plane;
3. sparse nodes;
4. refracted beam;
5. restrained scan plane;
6. pointer-responsive bloom.

Pointer and scroll variables are updated through one request-animation-frame scheduler. The script performs no network requests, analytics, storage, cookies, or evidence mutation.

## Zero-JavaScript records

The following documents intentionally execute no JavaScript and retain that contract:

- `404.html`
- `chat/index.html`
- `code/index.html`
- `diligence/index.html`
- `notes/index.html`
- `record/index.html`

They load the same neutral spectral language through the existing CSS-only adapter. Their route theme is already encoded in the body attributes created by the protected rollout controller.

## Performance tiers

- **Full** — all six layers and pointer depth.
- **Balanced** — reduced opacity and no scan plane on mobile or constrained hardware.
- **Quiet** — static beam and bloom for reduced-motion, data-saver, or low-resource devices.

No device signal is transmitted or retained.

## Accessibility

The existing 44-pixel targets, keyboard focus, Escape behavior, safe areas, responsive navigation, and semantic landmarks remain intact. The new layer adds explicit reduced-motion, increased-contrast, forced-colors, and print fallbacks. Content never depends on motion or hover.

## Truth boundary

- A reachable page proves reachability only.
- Committed policy intent is not proof of live deployment.
- Holographic layers do not establish authenticity, readiness, signature validity, or model quality.
- All verification claims remain bound to the existing record JSON, source links, and independent checks.
