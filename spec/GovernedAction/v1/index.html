Open specification

GovernedAction /v1

The open, offline-verifiable receipt predicate: a signed record of what a governed action was authorized to do, what it actually did, and whether the required evidence exists. Give the format away; sell the control plane above it.

Namespace

The canonical predicate type URI is https://szl.dev/GovernedAction/v1. While szl.dev completes registration, this page is the authoritative specification and the URI remains the stable public identifier — the URI denotes the specification; it is not a fetch endpoint.

Predicate type: https://szl.dev/GovernedAction/v1
Envelope: in-toto Statement v1 + DSSE signature
Schema: v1.schema.json (JSON Schema 2020-12)
Reference verifier: SZLHOLDINGS/prove-it (offline, in-browser; zero network during verification)
Reference implementation: szl-holdings/szl-receipt (Python, in-toto-attestation 0.9.3)

Core invariants (non-negotiable)

RuleMeaning
is_service_account === false on human_principalArticle 12 logging conformance requires identification of the natural persons involved in verification. A service account can never claim to be the human approver. Structurally enforced.
missing evidence ⇒ INCOMPLETENever PASS. Even with a valid signature, if any declared evidence obligation is unmet the verdict is INCOMPLETE, not forged success.
malformed is not forgedUndecodable or non-object payloads return UNAVAILABLE, not a security verdict.
PAE length over decoded bytesThe DSSE PAE length field counts decoded payload bytes, never the base64-encoded length. A verifier that uses the base64 length is silently bypassable.
transcript bindingEvery envelope carries a transcript_id; splice/reorder of single envelopes is MISMATCH.
signature ≠ truthA signature proves integrity and signer identity, not factual truth.

The four side-effect classes

Every governed action declares one of four side-effect classes: READ_ONLY, REVERSIBLE, COMPENSATABLE, IRREVERSIBLE. IRREVERSIBLE always requires human approval. They are never collapsed or reordered.

Verdict taxonomy

Six states, and no others: VERIFIED / MISMATCH / INCOMPLETE / PENDING_SYNC / UNSIGNED-LOCAL / UNAVAILABLE. Soft-state precedence is UNSIGNED-LOCAL > PENDING_SYNC > VERIFIED — a signed bundle that cannot still never renders as a pass.

EU AI Act framing

This predicate is an Article 12 logging conformance profile. It is never claimed as "EU AI Act compliant": applicability, classification, and deployer obligations are customer-specific. The retention floor for the fields defined here is six months.
