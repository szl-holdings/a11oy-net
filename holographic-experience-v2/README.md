# A11oy Holographic Evidence Vault v2

The proof origin is deliberately not a duplicate of the product command plane. `a11oy.net` remains a restrained, archival, evidence-first surface while sharing the same ecosystem navigation and accessibility grammar as `a-11-oy.com`.

## Design thesis

The Evidence Vault uses graphite depth, mint verification light, amber provenance light, ledger lanes, checksum constellations, and sparse orbital geometry. Its motion is quieter than the product origin and is decorative only. No animation establishes runtime health, signer availability, model capability, threat state, or proof validity.

## Two execution modes

The source binder preserves the existing no-JavaScript guarantees:

### Static evidence records

The following documents remain JavaScript-free and receive a CSS-only navigation rail:

- `404.html`
- `chat/index.html`
- `code/index.html`
- `diligence/index.html`
- `notes/index.html`
- `record/index.html`

The binder adopts the existing `.szl-proof-rail` or `.szl-proof-static-rail` when present rather than inserting a duplicate. When neither exists, it inserts a static five-journey rail.

### Interactive records

All other published HTML documents receive the local `szl-holo-proof-v2.js` progressive enhancement. It adds route-aware identity, restrained ambient geometry, scroll progress, optional panel material, and keyboard-accessible navigation. Native document content and links remain authoritative.

## Shared journeys

- Start — the proof front door
- Products — the product command origin
- Models — the estate atlas
- Kernels — the KHIPU record
- Proof — the RECORD index

## Accessibility contract

- minimum 44px interactive targets;
- visible keyboard focus;
- Escape-key closure for interactive mobile navigation;
- safe-area padding;
- no horizontal page overflow;
- reduced-motion, increased-contrast, forced-colors, and print behavior;
- CSS-only navigation remains horizontally scrollable on narrow screens.

## Performance and privacy

The implementation is first-party and dependency-free. It adds no analytics, tracking, cookies, browser storage, runtime fetch, third-party font, or CDN dependency. Pointer and scroll work is requestAnimationFrame-throttled and disabled or simplified for reduced motion, save-data, hidden documents, forced colors, and small screens.

## Truth boundary

The Evidence Vault is a presentation layer over existing proof material. It does not modify evidence JSON, hashes, claim labels, inventory counts, receipt stores, readiness endpoints, DNS, or product APIs. Decorative effects are explicitly marked as non-telemetry.

## Rollout sequence

1. Merge the assets, binder, tests, and workflows through protected main.
2. The one-shot rollout workflow creates `feat/holographic-proof-v2-bound` with exact document bindings.
3. Review and merge that binding branch through the repository's existing link, proof, diligence, and Pages checks.
4. Verify the live proof origin across mobile and desktop viewports.

The result is a premium proof network that feels connected to A11oy while remaining calmer, more forensic, and structurally independent from the product failure domain.
